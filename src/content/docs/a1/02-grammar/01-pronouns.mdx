Los pronombres reemplazan nombres para evitar repeticiones y hacen la comunicación más limpia. En inglés existen varios tipos de pronombres, pero los más importantes son los **pronombres de sujeto** (quién hace la acción), **pronombres de objeto** (quién recibe la acción) y **pronombres reflexivos** (cuando la acción recae sobre uno mismo), y dominarlos te permite hablar de manera más fluida y natural.

---

## Tipos de Pronombres

<Tabs>
  <TabItem label="Sujeto">
    Los pronombres de sujeto realizan la acción del verbo. Van **antes del verbo**:

    ```javascript
    const subjectPronouns = {
      "I": "I",      // yo
      "you": "you",  // tú/usted
      "he": "he",    // él
      "she": "she",  // ella
      "it": "it",    // eso/ello
      "we": "we",    // nosotros
      "they": "they" // ellos
    };
    ```

    **Ejemplos:**
    - **I** work here (Yo trabajo aquí)
    - **You** are smart (Tú eres inteligente)
    - **He** lives in Paris (Él vive en París)
    - **She** speaks Spanish (Ella habla español)
    - **It** is raining (Está lloviendo)
    - **We** are friends (Somos amigos)
    - **They** study English (Ellos estudian inglés)

    <Aside type="tip" title="Regla mnemotécnica para I mayúscula">
    **"I" siempre se escribe en mayúscula**, sin importar dónde esté en la oración: "I am happy" o "Sarah and I are friends".
    </Aside>

  </TabItem>
  
  <TabItem label="Objeto">
    Los pronombres de objeto reciben la acción del verbo. Van **después del verbo o preposición**:

    ```javascript
    const objectPronouns = {
      "I": "me",     // mí
      "you": "you",  // te/ti
      "he": "him",   // lo/le (a él)
      "she": "her",  // la/le (a ella)
      "it": "it",    // lo/la (eso)
      "we": "us",    // nos
      "they": "them" // los/las/les (a ellos)
    };
    ```

    **Ejemplos:**
    - Call **me** later (Llámame luego)
    - I see **you** (Te veo)
    - She loves **him** (Ella lo ama)
    - We know **her** (La conocemos)
    - Buy **it** now (Cómpralo ahora)
    - Tell **us** the truth (Dinos la verdad)
    - I'm with **them** (Estoy con ellos)

  </TabItem>
  
  <TabItem label="Reflexivos">
    Cuando el sujeto y el objeto son la misma persona, usamos pronombres reflexivos:

    ```javascript
    const reflexivePronouns = {
      "I": "myself",         // yo mismo/a
      "you": "yourself",     // tú mismo/a
      "he": "himself",       // él mismo
      "she": "herself",      // ella misma
      "it": "itself",        // eso mismo
      "we": "ourselves",     // nosotros mismos
      "they": "themselves"   // ellos mismos
    };
    ```

    **Ejemplos:**
    - I hurt **myself** (Me lastimé)
    - She prepared **herself** (Ella se preparó)
    - They defended **themselves** (Se defendieron)
    - Help **yourself**! (¡Sírvete!)

    <Aside type="note" title="Uso de pronombres reflexivos para énfasis">
    Los pronombres reflexivos también se usan para énfasis: "I **myself** don't agree" (Yo mismo no estoy de acuerdo).
    </Aside>

  </TabItem>
</Tabs>

**Ejemplos comparativos:**

- **I** like **him**, but **he** doesn't like **me** (Me gusta él, pero yo no le gusto a él)
- **She** knows **us**, and **we** know **her** (Ella nos conoce, y nosotros la conocemos)
- **They** invited **you**, did **you** invite **them**? (Ellos te invitaron, ¿tú los invitaste?)
- I talk to **myself** when I'm alone (Hablo conmigo mismo cuando estoy solo)

## Casos Especiales

<Tabs>
  <TabItem label="Pronombre It">

El pronombre **it** tiene usos especiales en inglés:

```javascript
const itUses = [
  'The book is new. It is expensive', // Cosas: El libro es nuevo. Es caro
  'The cat is hungry. Feed it', // Animales: El gato tiene hambre. Dale de comer
  'It is raining / It is cold', // Clima: Está lloviendo / Hace frío
  'It is 3 PM / It is late', // Hora: Son las 3 PM / Es tarde
  'It is 5 km to the city', // Distancia: Está a 5 km de la ciudad
  'It is difficult / It is important', // Situaciones: Es difícil / Es importante
];
```

**Ejemplos:**

- Where is my phone? **It** is on the table (¿Dónde está mi teléfono? Está en la mesa)
- **It** is sunny today (Está soleado hoy)
- **It** is important to study (Es importante estudiar)
- I found a wallet. I gave **it** to the police (Encontré una cartera. La di a la policía)

<Aside type="note" title="Uso de it para animales">
  En inglés, **it** se usa para animales cuando no sabemos el sexo o cuando hablamos en general. Si conoces el sexo,
  puedes usar he/she: "My dog is smart. **He** loves to play".
</Aside>

  </TabItem>

  <TabItem label="Pronombre You">

**You** es único porque sirve para singular y plural, formal e informal:

```javascript
let meaning = '';

// Singular
if (target === 'one person') meaning = 'Tú eres mi amigo';
if (target === 'manager') meaning = 'Usted es el gerente';

// Plural
if (target === 'group') meaning = 'Ustedes/Vosotros son mis amigos';
```

**Ejemplos:**

- Are **you** ready, John? (¿Estás listo, John?)
- Are **you** ready, everyone? (¿Están listos, todos?)

    </TabItem>
</Tabs>

## Reglas de Uso

<Tabs>
  <TabItem label="Después de Preposiciones">

Las preposiciones (palabras como for, with, to, about, between) **siempre** van seguidas de pronombres de objeto, nunca de sujeto.

```javascript
const commonPrepositions = [
  'for', // para/por
  'with', // con
  'to', // a/hacia
  'about', // sobre/acerca de
  'between', // entre
];
```

**Ejemplos:**

- This gift is for **you** (Este regalo es para ti)
- She is talking to **me** (Ella está hablando conmigo)
- Come with **us** (Ven con nosotros)
- I am thinking about **him** (Estoy pensando en él)
- Sit next to **her** (Siéntate junto a ella)
- The secret is between **you and me** (El secreto es entre tú y yo)

<Aside type="note" title="Excepción con by para expresar solo/sola">
Los pronombres reflexivos se usan con "by" para indicar hacer algo sin ayuda o en soledad:

- I did it **by myself** (Lo hice yo solo)
- She lives **by herself** (Ella vive sola)
- They finished **by themselves** (Terminaron ellos solos)

  </Aside>

    </TabItem>

    <TabItem label="Construcciones con And">

Cuando unes varios sujetos u objetos usando "and", aplica la misma regla. Usa pronombres de sujeto si realizan la acción o de objeto si la reciben. Para decidir, imagina la oración sin la otra persona ("Sarah and I went" funciona porque "I went" es correcto).

```javascript
const multiplePeople = {
  subjects: 'Sarah and I', // Actúan
  objects: 'Sarah and me', // Reciben
  reflexives: 'ourselves', // Reflejan a plural
};
```

**Ejemplos:**

- **Sarah and I** went to the store (Sarah y yo fuimos a la tienda)
- The teacher called **John and me** (El profesor nos llamó a John y a mí)
- **He and I** did it **ourselves** (Él y yo lo hicimos nosotros mismos)
- **You and Sarah** can defend **yourselves** (Tú y Sarah pueden defenderse ustedes mismos)
- **Mary and Tom** bought it for **themselves** (Mary y Tom lo compraron para ellos mismos)

<Aside type="tip" title="Regla de cortesía al mencionarte con otros">
  Como norma de educación, cuando te incluyes con otras personas siempre debes mencionarte al **final**: "Sarah and I" o
  "John and me".
</Aside>

  </TabItem>
</Tabs>

## Errores Comunes

<Aside type="danger" title="Usar pronombre de sujeto después de preposición">
Las preposiciones siempre requieren pronombres de objeto en lugar de los de sujeto.

- This is for **I** / Come with **we** / Between **she** and **I** ⛔
- This is for **me** (Esto es para mí) ✅
- Come with **us** (Ven con nosotros) ✅
- Between **her** and **me** (Entre ella y yo) ✅
  </Aside>

<Aside type="danger" title="Confundir he/she con him/her">
Es importante distinguir cuando son sujetos o cuando reciben la acción (objeto).

- I like **she** / **Him** called me ⛔
- I like **her** (Me gusta ella) ✅
- **He** called me (Él me llamó) ✅
- **She** is my friend (Ella es mi amiga) ✅
  </Aside>

<Aside type="danger" title="Orden incorrecto con and I / and me">
Es una regla de cortesía ponerse a sí mismo al final al mencionarse junto con otros.

- **I** and John went / **Me** and Sarah like pizza ⛔
- John and **I** went (John y yo fuimos) ✅
- Sarah and **I** like pizza (A Sarah y a mí nos gusta la pizza) ✅
  </Aside>

<Aside type="danger" title="No escribir I en mayúscula">
El pronombre yo siempre va en mayúscula obligatoriamente, sin importar su posición u otras reglas.

- **i** am happy / My friend and **i** ⛔
- **I** am happy (Estoy feliz) ✅
- My friend and **I** (Mi amigo y yo) ✅
  </Aside>
