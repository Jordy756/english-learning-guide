Los **phrasal verbs** (verbos compuestos) combinan un verbo base con una o más partículas (preposiciones o adverbios) para crear un significado completamente nuevo. Su significado no se puede deducir de las partes por separado: "turn on" no significa "girar en", sino "encender". Son extremadamente comunes en inglés hablado y escrito, y aparecen constantemente en conversaciones cotidianas.

---

## Estructura de los Phrasal Verbs

Un phrasal verb consta de dos o tres elementos: un verbo base y una o más partículas. El resultado tiene un significado propio que no se puede deducir de cada palabra por separado.

```javascript
const turn = {
  'turn on': 'encender', // Turn on the light
  'turn off': 'apagar', // Turn off the TV
  'turn into': 'convertirse en', // Water turned into ice
};
// verbo + partícula → nuevo significado
// distinto del significado literal de cada parte
```

---

## Phrasal Verbs Separables e Inseparables

La característica más importante es saber si puedes separar el verbo de la partícula:

<Tabs>
  <TabItem label="Separables">
    Los phrasal verbs separables permiten que el objeto se coloque entre el verbo y la partícula. De hecho, cuando el objeto es un pronombre, **DEBE** ir en el medio.

    ```javascript
    const separable = {
      structure: "verb + object + particle OR verb + particle + object",
      examples: [
        { phrase: "turn on the light", meaning: "enciende la luz" },
        { phrase: "turn the light on", meaning: "enciende la luz" },
        { phrase: "turn it on", meaning: "enciéndelo" }, // SIEMPRE separado
        { phrase: "put off the meeting", meaning: "aplaza la reunión" },
        { phrase: "put the meeting off", meaning: "aplaza la reunión" },
        { phrase: "put it off", meaning: "apázalo" }
      ]
    };
    ```

    **Ejemplos:**

    - **Turn on** the lights before you leave (Enciende las luces antes de irte)
    - She **put off** the meeting until Friday (Ella aplazó la reunión hasta el viernes)
    - He **picked it up** from the floor (Él lo recogió del suelo)
    - I need to **call off** the event (Necesito cancelar el evento)

  </TabItem>

  <TabItem label="Inseparables">
    Los phrasal verbs inseparables mantienen el verbo y la partícula juntos siempre. El objeto nunca va en el medio.

    ```javascript
    const inseparable = {
      structure: "verb + particle + object",
      examples: [
        { phrase: "look for the keys", meaning: "busca las llaves" },
        { phrase: "look for them", meaning: "búscalas" },
        { phrase: "look the keys for", meaning: "incorrecto" },
        { phrase: "get over the problem", meaning: "superé el problema" },
        { phrase: "run into an old friend", meaning: "me encontré con un viejo amigo" },
        { phrase: "go through the document", meaning: "revisa el documento" }
      ]
    };
    ```

    **Ejemplos:**

    - I **looked for** my keys everywhere (Busqué mis llaves por todas partes)
    - She needs to **get over** the breakup (Ella necesita superar la ruptura)
    - I **ran into** an old friend at the store (Me encontré con un viejo amigo en la tienda)
    - Can you **look after** the kids tonight? (¿Puedes cuidar a los niños esta noche?)

  </TabItem>
</Tabs>

## Phrasal Verbs de 3 Partes

Algunos phrasal verbs están formados por **tres elementos**: verbo + dos partículas. Estos son particularmente interesantes porque combinan preposiciones o adverbios de formas únicas que crean significados completamente nuevos.

La estructura es: **verb + adverb/preposition + preposition**

```javascript
const threePartPhrasalVerbs = [
  { phrasal: 'put up with', meaning: 'tolerar, aguantar' },
  { phrasal: 'get along with', meaning: 'llevarse bien con' },
  { phrasal: 'keep up with', meaning: 'mantenerse al día' },
  { phrasal: 'look forward to', meaning: 'esperar con entusiasmo' },
  { phrasal: 'run away with', meaning: 'escaparse con' },
];
```

<Aside type="caution" title="Los phrasal verbs de 3 partes nunca se separan">
  Los phrasal verbs de 3 partes **SIEMPRE son inseparables**. El patrón es: verb + particle 1 + particle 2 + object. La
  estructura nunca se divide.
</Aside>

## Phrasal Verbs más comunes

Aquí están algunos de los phrasal verbs más usados, agrupados por verbo base:

<Tabs>
  <TabItem label="Turn">
    ```javascript
    const turnPhrasalVerbs = [
      { phrasal: "turn on",   meaning: "encender" },
      { phrasal: "turn off",  meaning: "apagar" },
      { phrasal: "turn up",   meaning: "subir el volumen" },
      { phrasal: "turn down", meaning: "bajar/rechazar" },
      { phrasal: "turn into", meaning: "convertirse en" },
    ];
    ```

    **Ejemplos:**

    - **Turn on** the TV, please (Enciende la televisión, por favor)
    - She **turned down** the job offer (Ella rechazó la oferta de trabajo)
    - The caterpillar **turned into** a butterfly (La oruga se convirtió en mariposa)

  </TabItem>

  <TabItem label="Get">
    ```javascript
    const getPhrasalVerbs = [
      { phrasal: "get up",   meaning: "levantarse" },
      { phrasal: "get off",  meaning: "bajarse de" },
      { phrasal: "get over", meaning: "recuperarse, superar" },
      { phrasal: "get back", meaning: "regresar, devolver" },
      { phrasal: "get along", meaning: "llevarse bien" },
    ];
    ```

    **Ejemplos:**

    - I **get up** at 7 every morning (Me levanto a las 7 todas las mañanas)
    - She finally **got over** the flu (Ella finalmente se recuperó de la gripe)
    - We need to **get back** before 9 PM (Necesitamos regresar antes de las 9 PM)

  </TabItem>

  <TabItem label="Look">
    ```javascript
    const lookPhrasalVerbs = [
      { phrasal: "look for",      meaning: "buscar" },
      { phrasal: "look at",       meaning: "mirar" },
      { phrasal: "look after",    meaning: "cuidar de" },
      { phrasal: "look forward to", meaning: "esperar con entusiasmo" },
    ];
    ```

    **Ejemplos:**

    - I'm **looking for** my passport (Estoy buscando mi pasaporte)
    - Can you **look after** the dog this weekend? (¿Puedes cuidar al perro este fin de semana?)
    - I'm **looking forward to** the holidays (Espero las vacaciones con entusiasmo)

  </TabItem>
</Tabs>

## Errores Comunes

<Aside type="danger" title="Separar phrasal verbs inseparables">
Los phrasal verbs inseparables nunca pueden dividirse: el objeto siempre va después de la partícula, nunca en el medio.

- I **looked** the keys **for** ⛔
- I **looked for** the keys (Busqué las llaves) ✅
- She **ran** him **into** ⛔
- She **ran into** him (Se lo encontró) ✅
  </Aside>

<Aside type="danger" title="No separar phrasal verbs separables con pronombres">
Cuando el objeto es un pronombre, los phrasal verbs separables siempre deben dividirse. El pronombre va en el medio, nunca al final.

- I **turned on it** ⛔
- I **turned it on** (Lo encendí) ✅
- She **picked up them** ⛔
- She **picked them up** (Los recogió) ✅
  </Aside>

<Aside type="danger" title="Diferenciar phrasal verbs similares">
Algunos phrasal verbs parecidos tienen un comportamiento distinto. Por ejemplo, "take off" es separable y "get off" es inseparable.

- Take off your shoes **off** ⛔
- **Take off** your shoes (Quítate los zapatos) ✅
- Get **the bus** off ⛔
- **Get off** the bus (Bájate del autobús) ✅
  </Aside>

<Aside type="danger" title="Uso incorrecto del pasado">
Los phrasal verbs regulares forman el pasado con **-ed**, igual que cualquier verbo regular. El objeto tampoco puede omitirse si la oración lo requiere.

- I **looked for** yesterday ⛔
- I **looked for** it yesterday (Lo busqué ayer) ✅
- She **turned on** already ⛔
- She **turned it on** already (Ella ya lo encendió) ✅
  </Aside>
