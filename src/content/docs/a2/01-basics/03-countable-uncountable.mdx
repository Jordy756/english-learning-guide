Los sustantivos en inglés se dividen en dos categorías fundamentales: **contables** e **incontables**. Los contables son palabras que representan cosas que puedes contar de forma individual, mientras que los incontables representan materiales, sustancias o conceptos que no se dividen en unidades separadas. Esta distinción determina qué artículos y cuantificadores puedes usar con cada sustantivo. Muchos errores comunes de hispanohablantes vienen de no reconocer qué sustantivos son incontables en inglés.

---

## Tipos de Sustantivos

<Tabs>
  <TabItem label="Contables">

Los sustantivos **contables** son cosas que puedes contar individualmente. Tienen forma singular y plural.

```javascript
const countableNouns = [
  "a book / two books",      // un libro / dos libros
  "an apple / five apples",  // una manzana / cinco manzanas
  "a car / three cars",      // un carro / tres carros
  "a person / many people"   // una persona / muchas personas
];
```

**Ejemplos:**

- I have **three books** (Tengo tres libros)
- She bought **two apples** (Ella compró dos manzanas)
- There are **five people** waiting (Hay cinco personas esperando)
- We visited **many countries** (Visitamos muchos países)
- He owns **a car** and **a motorcycle** (Él tiene un carro y una motocicleta)

</TabItem>

  <TabItem label="Incontables">

Los sustantivos **incontables** son materiales, líquidos, o conceptos que **no puedes dividir en unidades individuales**.

```javascript
const uncountableNouns = [
  "water",        // agua (no "a water")
  "information",  // información (no "an information")
  "money",        // dinero (no "a money")
  "furniture",    // muebles (no "a furniture")
  "advice"        // consejo (no "an advice")
];
```

**Ejemplos:**

- I drink **water** every day (Tomo agua todos los días)
- She needs **information** (Ella necesita información)
- They bought **furniture** (Compraron muebles)
- We don't have **time** (No tenemos tiempo)
- He gave me good **advice** (Él me dio buen consejo)

<Aside type="caution" title="Incontables que confunden a hispanohablantes">
Estos son **incontables** en inglés pero contables en español: 
- **Information** (información)
- **Advice** (consejo)
- **Furniture** (muebles)
- **Luggage** (equipaje)
- **Homework** (tarea)
- **Bread** (pan)
- **Rice** (arroz).
- **Hair** (cabello)
</Aside>

</TabItem>
</Tabs>

## Uso de A/An

Los artículos **a/an** (un/una) solo se usan con sustantivos **contables singulares**. Nunca con incontables.

<Tabs>
  <TabItem label="Contables">

```javascript
const withA = ["a book", "a car", "a sandwich"];
// consonante → usa a
const withAn = ["an apple", "an idea", "an umbrella"];
// vocal → usa an
```

**Ejemplos:**

- I want **a sandwich** (Quiero un sándwich)
- She needs **an umbrella** (Ella necesita un paraguas)
- He's reading **a book** (Él está leyendo un libro)
- We saw **an elephant** (Vimos un elefante)

</TabItem>

  <TabItem label="Incontables">

```javascript
// Contable → usa a/an
"a book";             // un libro ✅
// Incontable → usa some
"some water";         // algo de agua ✅
"some information";   // algo de información ✅
// Incontable con contenedor
"a glass of water";   // un vaso de agua ✅
"a piece of advice";  // un consejo ✅
```

**Ejemplos:**

- I need **water** (not "a water")
- I need **some water** (Necesito agua)
- She wants **information** (not "an information")  
- She wants **some information** (Ella quiere información)

</TabItem>
</Tabs>

## Uso de Some y Any

**Some** (algo de/algunos) y **any** (algo de/ningún) se usan con sustantivos **contables en plural** e **incontables**.

<Tabs>
  <TabItem label="Some (Afirmativas)">

Usa **some** en oraciones **afirmativas** para indicar una cantidad indefinida.

```javascript
const someUsage = {
  countable: "I have some books",        // Tengo algunos libros
  uncountable: "I have some money"       // Tengo algo de dinero
};
```

**Ejemplos:**

- We need **some apples** (Necesitamos algunas manzanas) - contable
- They have **some water** (Tienen algo de agua) - incontable
- She bought **some chairs** (Ella compró algunas sillas) - contable
- I want **some information** (Quiero algo de información) - incontable

</TabItem>

  <TabItem label="Any (Negativas/Preguntas)">

Usa **any** en oraciones **negativas** y **preguntas**.

```javascript
const anyUsage = {
  question: "Do you have any books?",       // ¿Tienes algunos libros?
  negative: "I don't have any money"        // No tengo dinero
};
```

**Ejemplos:**

- Do you have **any eggs**? (¿Tienes huevos?) - pregunta, contable
- Is there **any milk**? (¿Hay leche?) - pregunta, incontable
- We don't have **any chairs** (No tenemos sillas) - negativa, contable
- I don't need **any help** (No necesito ayuda) - negativa, incontable

</TabItem>

  <TabItem label="Some en Preguntas (Ofrecimientos)">

Usa **some** en preguntas cuando **ofreces** algo o **pides** algo de manera cortés.

```javascript
const someInQuestions = {
  offering: "Would you like some coffee?",      // ¿Te gustaría café?
  requesting: "Can I have some water?"          // ¿Puedo tener agua?
};
```

**Ejemplos:**

- Would you like **some cookies**? (¿Te gustarían algunas galletas?)
- Can I have **some advice**? (¿Puedo recibir algún consejo?)
- Do you want **some help**? (¿Quieres ayuda?)

</TabItem>
</Tabs>

## Contenedores y Unidades

Para contar sustantivos incontables, usa un **contenedor, porción o unidad** antes del sustantivo. El patrón siempre es: artículo + contenedor + "of" + sustantivo incontable.

<Tabs>
  <TabItem label="Bebidas">

```javascript
const drinkContainers = {
  glass: "a glass of",       // un vaso de
  cup: "a cup of",           // una taza de
  mug: "a mug of",           // una taza grande de
  bottle: "a bottle of",     // una botella de
  can: "a can of",           // una lata de
  carton: "a carton of",     // un cartón de
  jug: "a jug of"            // una jarra de
};
```

  **Ejemplos:**

  - I'd like **a glass of** water (Me gustaría un vaso de agua)
  - She ordered **a cup of** coffee (Ella pidió una taza de café)
  - We bought **a loaf of** bread (Compramos una barra de pan)
  - He ate **a bowl of** soup (Él comió un tazón de sopa)
  - They shared **a piece of** cake (Ellos compartieron un pedazo de pastel)

  </TabItem>

  <TabItem label="Porciones y Materiales">

Para ingredientes de cocina o materiales físicos, usa unidades de medida.

```javascript
const portions = {
  spoonful: "a spoonful of sugar", // una cucharada de azúcar
  pinch: "a pinch of salt",        // una pizca de sal
  drop: "a drop of oil",           // una gota de aceite
  sheet: "a sheet of paper",       // una hoja de papel
  roll: "a roll of tape",          // un rollo de cinta
  tube: "a tube of toothpaste"     // un tubo de pasta dental
};
```

  **Ejemplos:**

  - Add **a pinch of** salt (Añade una pizca de sal)
  - She used **a spoonful of** honey (Ella usó una cucharada de miel)
  - Give me **a sheet of** paper (Dame una hoja de papel)
  - He bought **a tube of** toothpaste (Él compró un tubo de pasta dental)
  - We need **a roll of** toilet paper (Necesitamos un rollo de papel higiénico)

  </TabItem>

  <TabItem label="Conceptos y Grupos">

Para ideas abstractas o colecciones, usa palabras como "piece", "bit" o "bunch".

```javascript
const abstract = {
  piece: "a piece of advice",  // un consejo
  bit: "a bit of help",        // un poco de ayuda
  item: "an item of clothing", // una prenda de ropa
  bunch: "a bunch of grapes",  // un racimo de uvas
  pile: "a pile of clothes",   // un montón de ropa
  load: "a load of laundry"    // una carga de ropa
};
```

  **Ejemplos:**

  - Can you give me **a piece of** advice? (¿Puedes darme un consejo?)
  - I need **a bit of** help (Necesito un poco de ayuda)
  - She bought **an item of** clothing (Ella compró una prenda de ropa)
  - He picked **a bunch of** flowers (Él recogió un ramo de flores)
  - There's **a pile of** work to do (Hay un montón de trabajo por hacer)

  </TabItem>
</Tabs>

## Errores Comunes

<Aside type="danger" title="Usar a/an con sustantivos incontables">
Los sustantivos incontables nunca llevan a/an. Usa some, o un contenedor como "a glass of water".

- I need **a** water ⛔
- I need **some** water (Necesito agua) ✅
- She wants **an** information ⛔
- She wants **some** information (Ella quiere información) ✅
</Aside>

<Aside type="danger" title="Pluralizar sustantivos incontables">
Los sustantivos incontables no tienen forma plural. Usa contenedores o unidades para expresar cantidad.

- I have two **breads** ⛔
- I have two **loaves of bread** (Tengo dos barras de pan) ✅
- We need three **furnitures** ⛔
- We need three **pieces of furniture** (Necesitamos tres muebles) ✅
</Aside>

<Aside type="danger" title="Tratar 'advice', 'information', 'furniture' como contables">
Estos sustantivos son incontables en inglés aunque funcionen como contables en español. Nunca llevan artículo ni forma plural.

- Can you give me **an advice**? ⛔
- Can you give me **some advice**? (¿Puedes darme un consejo?) ✅
- I need **informations** ⛔
- I need **some information** (Necesito información) ✅
</Aside>

<Aside type="danger" title="Usar 'any' en afirmativas">
En oraciones afirmativas se usa some, no any. El uso de any se reserva para negativas y preguntas.

- I have **any** money ⛔
- I have **some** money (Tengo dinero) ✅
- We bought **any** apples ⛔
- We bought **some** apples (Compramos manzanas) ✅
</Aside>

<Aside type="danger" title="Confundir 'much' y 'many'">
Many se usa con sustantivos contables y much con incontables. Intercambiarlos produce oraciones incorrectas.

- There are **much** people ⛔
- There are **many** people (Hay muchas personas) ✅
- I don't have **many** money ⛔
- I don't have **much** money (No tengo mucho dinero) ✅
</Aside>

## Práctica

<Aside type="tip" title="Ejercicio diario">
- Clasifica 20 sustantivos como contables o incontables (libro, agua, consejo, silla, dinero, etc.)
- Completa oraciones con a/an/some/any: "I need ___ water", "Do you have ___ books?", "She doesn't have ___ time"
- Transforma sustantivos incontables usando contenedores: "water" → "a glass of water", "bread" → "a loaf of bread"
- Lee un artículo en inglés y subraya todos los sustantivos incontables, verifica si se usan correctamente
- Practica con comida: haz una lista de compras usando some/any correctamente
</Aside>
