Los **cuantificadores** son palabras que indican cantidad sin especificar un número exacto. La clave para usarlos bien es reconocer si el sustantivo que los acompaña es contable o incontable, porque cada cuantificador solo funciona con uno de los dos tipos, o con ambos. Elegir el incorrecto es uno de los errores más frecuentes en el inglés de hispanohablantes.

---

## Much vs Many

**Much** y **many** significan "mucho/mucha/muchos/muchas". Usa **many** con sustantivos **contables en plural** y **much** con sustantivos **incontables**. En oraciones afirmativas es más natural usar **a lot of** en lugar de **much** — decir "I have much time" suena muy formal.

```javascript
const getQuantifier = (noun, type) => {
  return type === 'countable'
    ? `many ${noun}` // many books, many people
    : `much ${noun}`; // much water, much time
};

// getQuantifier("books", "countable")   → "many books"
// getQuantifier("money", "uncountable") → "much money"
```

**Ejemplos:**

- How **many books** do you have? (¿Cuántos libros tienes?)
- There are **many people** here (Hay muchas personas aquí)
- She visited **many cities** (Ella visitó muchas ciudades)
- I don't have **many friends** in this city (No tengo muchos amigos en esta ciudad)
- Do you have **many questions**? (¿Tienes muchas preguntas?)
- How **much water** do you drink? (¿Cuánta agua tomas?)
- I don't have **much time** (No tengo mucho tiempo)
- She doesn't earn **much money** (Ella no gana mucho dinero)
- There isn't **much information** available (No hay mucha información disponible)
- Do you need **much help**? (¿Necesitas mucha ayuda?)

## A Lot Of / Lots Of

**A lot of** y **lots of** significan "muchos/muchas" y funcionan con **ambos tipos** de sustantivos — contables e incontables por igual.

```javascript
const examples = [
  'a lot of books', // contable → muchos libros
  'a lot of water', // incontable → mucha agua
  'lots of people', // contable → muchas personas
  'lots of time', // incontable → mucho tiempo
];
// funciona igual con contables e incontables
```

- I have **a lot of books** (Tengo muchos libros)
- I drink **a lot of water** (Tomo mucha agua)
- There are **lots of people** here (Hay muchas personas aquí)
- We have **lots of time** (Tenemos mucho tiempo)
- She knows **a lot of languages** (Ella sabe muchos idiomas)
- She makes **a lot of money** (Ella gana mucho dinero)
- He needs **a lot of help** (Él necesita mucha ayuda)

<Aside type="note" title="Lots of vs a lot of">
  **Lots of** es más informal que **a lot of** pero el uso es idéntico.
</Aside>

## A Little vs A Few

**A little** y **a few** significan "un poco de/unos pocos", indicando una **cantidad pequeña**.

<Tabs>
  <TabItem label="A Few">

Usa **a few** con sustantivos **contables en plural** para indicar una **cantidad pequeña pero suficiente**.

```javascript
const aFewExamples = [
  'a few books', // unos pocos libros
  'a few friends', // unos pocos amigos
  'a few days', // unos días
  'a few questions', // unas preguntas
];
// contables en plural: cantidad pequeña pero suficiente
```

**Ejemplos:**

- I have **a few books** to read (Tengo unos pocos libros para leer)
- She has **a few friends** here (Ella tiene unos pocos amigos aquí)
- Wait **a few minutes** (Espera unos minutos)
- I have **a few questions** (Tengo unas preguntas)
- We met **a few people** at the party (Conocimos a unas personas en la fiesta)

</TabItem>

  <TabItem label="A Little">

Usa **a little** con sustantivos **incontables** para indicar una **cantidad pequeña pero suficiente**.

```javascript
const aLittle = (noun) => `a little ${noun}`;
// aLittle("water")       → "a little water"
// aLittle("time")        → "a little time"
// aLittle("money")       → "a little money"
// incontables: cantidad pequeña pero suficiente
```

**Ejemplos:**

- I need **a little water** (Necesito un poco de agua)
- We have **a little time** (Tenemos un poco de tiempo)
- She has **a little money** saved (Ella tiene un poco de dinero ahorrado)
- There's **a little milk** left (Queda un poco de leche)
- I speak **a little English** (Hablo un poco de inglés)

</TabItem>

  <TabItem label="Sin 'A': Few vs Little">

**Sin el artículo "a"**, el significado cambia a una connotación más **negativa** (casi nada):

```javascript
const aFew = 'a few friends'; // algunos — suficiente
const few = 'few friends'; // pocos — insuficiente

const aLittle = 'a little time'; // algo — suficiente
const little = 'little time'; // casi nada — insuficiente
```

**Ejemplos:**

- I have **a few friends** (Tengo algunos amigos)
- I have **few friends** (Tengo pocos amigos, casi ninguno)
- We have **a little time** (Tenemos un poco de tiempo)
- We have **little time** (Tenemos muy poco tiempo, es insuficiente)

<Aside type="caution" title="La diferencia sutil entre 'a few/little' y 'few/little'">
  El artículo **"a"** hace una gran diferencia. **A few/a little** indica que hay **algo suficiente** (tono positivo).
  Sin "a", **few/little** indica una cantidad **insuficiente** o **escasa** (tono negativo).
</Aside>

</TabItem>
</Tabs>

## Too Much / Too Many / Too / Enough

Estos cuantificadores expresan **exceso** (too much/many) o **suficiencia** (enough).

<Tabs>
  <TabItem label="Too Many / Too Much">

**Too many** se usa con contables en plural y **too much** con incontables. Ambos indican que la cantidad supera lo deseable.

```javascript
const tooQuantifier = (noun, type) => {
  return type === 'countable'
    ? `too many ${noun}` // demasiados/as
    : `too much ${noun}`; // demasiado/a
};
// tooQuantifier("books", "countable")   → "too many books"
// tooQuantifier("water", "uncountable") → "too much water"
```

**Ejemplos:**

- There are **too many people** here (Hay demasiadas personas aquí)
- You ask **too many questions** (Haces demasiadas preguntas)
- There's **too much noise** (Hay demasiado ruido)
- You drink **too much coffee** (Tomas demasiado café)
- She has **too much work** (Ella tiene demasiado trabajo)

  </TabItem>

  <TabItem label="Too">

**Too** significa "demasiado" con **adjetivos** y **adverbios** para indicar exceso. Siempre se coloca antes de la palabra que modifica.

```javascript
const tooExamples = [
  'too hot', // demasiado caliente
  'too difficult', // demasiado difícil
  'too fast', // demasiado rápido
  'too long', // demasiado largo
];
// posición: too + adjetivo/adverbio
```

**Ejemplos:**

- The coffee is **too hot** (El café está demasiado caliente)
- This exercise is **too difficult** (Este ejercicio es demasiado difícil)
- She speaks **too fast** (Ella habla demasiado rápido)
- The movie was **too long** (La película fue demasiado larga)

  </TabItem>

  <TabItem label="Enough">

**Enough** significa "suficiente" y funciona con **ambos tipos** de sustantivos. Con sustantivos siempre va antes; con adjetivos va después.

```javascript
const enough = (noun, pos) => {
  return pos === 'adj'
    ? noun + ' enough' // good enough → después del adj
    : 'enough ' + noun; // enough money → antes del sust
};
```

**Ejemplos:**

- Do we have **enough chairs**? (¿Tenemos suficientes sillas?)
- Is there **enough water**? (¿Hay suficiente agua?)
- We don't have **enough time** (No tenemos suficiente tiempo)
- Is the room **big enough**? (¿Es el cuarto suficientemente grande?)
- She doesn't study **hard enough** (Ella no estudia suficientemente duro)

    </TabItem>
</Tabs>

## Errores Comunes

<Aside type="danger" title="Confundir much con many en contables plurales">
Many va con contables en plural y much con incontables. Intercambiarlos produce oraciones incorrectas.

- How **much** books do you have? ⛔
- How **many books** do you have? (¿Cuántos libros tienes?) ✅
- I don't have **much** friends ⛔
- I don't have **many friends** (No tengo muchos amigos) ✅
  </Aside>

<Aside type="danger" title="Usar much en afirmativas suena poco natural">
En oraciones afirmativas, much suena muy formal o anticuado. La forma natural es a lot of.

- I have **much** money ⛔
- I have **a lot of money** (Tengo mucho dinero) ✅
- We have **much** time ⛔
- We have **a lot of time** (Tenemos mucho tiempo) ✅
  </Aside>

<Aside type="danger" title="Confundir a few con a little">
A few es para contables en plural y a little para incontables. No son intercambiables.

- I have **a little** friends ⛔
- I have **a few friends** (Tengo unos pocos amigos) ✅
- She needs **a few** water ⛔
- She needs **a little water** (Ella necesita un poco de agua) ✅
  </Aside>

<Aside type="danger" title="Poner enough después del sustantivo">
Con sustantivos, enough siempre va antes. Solo va después cuando modifica adjetivos o verbos.

- We don't have money **enough** ⛔
- We don't have **enough money** (No tenemos suficiente dinero) ✅
- There isn't time **enough** ⛔
- There isn't **enough time** (No hay suficiente tiempo) ✅
  </Aside>

<Aside type="danger" title="Omitir too cuando quieres expresar exceso">
Many y much solos indican cantidad. Para expresar exceso necesitas añadir too delante.

- I have **many** problems ⛔ (queriendo decir demasiados)
- I have **too many problems** (Tengo demasiados problemas) ✅
- There is **much** noise ⛔ (queriendo decir demasiado)
- There is **too much noise** (Hay demasiado ruido) ✅
  </Aside>
